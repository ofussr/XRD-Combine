# XRD Combine

Версия 2.9.13.

Единое настольное приложение для просмотра и первичной обработки данных
рентгеновской дифракции.

Верхний уровень интерфейса разделён на три постоянных раздела: **Просмотр**,
**Структуры** и **Полюсные фигуры**. Слева расположена общая сворачиваемая панель
объектов проекта. Галочка в ней подключает объект к текущему разделу; цвет,
порядок и видимость остаются локальными настройками соответствующей страницы.

Интерфейс доступен на английском, французском и русском языках. Язык по
умолчанию – английский; переключатель находится в меню **Edit → Language**.
Выбор сохраняется для следующего запуска.

Текущее разделение кода и порядок подготовки PySide6-интерфейса описаны в
[`ARCHITECTURE.md`](ARCHITECTURE.md).

## Изменения в 2.9.13

- Раскладка подписей hkl теперь действительно имеет два режима. При включённых
  линиях разрешены удалённые свободные позиции с выносками; при выключенных
  линиях подпись ищет место только рядом с краем своей точки. Если компактного
  свободного места нет, второстепенная подпись не выводится, а выбранная точка
  остаётся приоритетной.
- Для выбранной точки экспериментального графика на оси 2θ показывается
  межплоскостное расстояние d, рассчитанное по текущей общей длине волны и уже
  отображаемой координате с учётом ручного сдвига X. Для многолинейного
  излучения d выводится отдельно для каждой линии; для остальных типов осей
  значение не подставляется.
- Статические элементы основных страниц и вспомогательных окон Tkinter,
  которые уже присутствуют в каталогах, переведены с распознавания видимого
  текста на устойчивые ключи. Tk-адаптер закрепляет найденный ключ за виджетом
  при первом применении языка.
- Новых библиотек и дополнительных файлов для PyInstaller не добавлено.

## Изменения в 2.9.12

- Обводка точек, соответствующих нескольким совпадающим полюсам, возвращена
  как отдельная опция. По умолчанию она выключена и не влияет на красное
  выделение выбранного полюса.
- Линии от точек к вынесенным подписям hkl получили собственную галочку и по
  умолчанию не рисуются. Без включённых подписей hkl галочка линий неактивна.
- Параметры второй фазы скрыты, пока она не загружена; в блоке остаются только
  элементы выбора и открытия.
- Основную фазу теперь можно повторно загрузить как вторую. Обе копии имеют
  независимые центрирование, ориентацию и стиль, но в Project data сохраняется один
  объект. Удаление второй копии не выгружает основную.
- Для второй фазы добавлено совместное вращение. При включённой галочке мышь,
  центрирование, совмещение, абсолютный и относительный повороты первой фазы
  поворачивают обе. Управление второй фазы по-прежнему меняет только её. Связь выполняется
  через матрицу приращения, поэтому собственное центрирование второй фазы сохраняется.
- Галочка базисных векторов неактивна, если трёхмерная структура рядом с полюсной
  фигурой не показана.

## Изменения в 2.9.9

- Раздел добавления второй фазы перенесён в конец панели управления расчётной
  полюсной фигуры, после настроек и совмещения первой фазы.
- Для второй фазы добавлены отдельные команды совмещения выбранного полюса с

  её центрирование и принадлежащие ей расчётные данные; выбранная точка любой
  фазы получает обводку.
- Если точки разных фаз практически совпадают, возле курсора открывается
  компактный список фаз и отражений для однозначного выбора.
- Фиксированные смещения подписей заменены автоматической раскладкой в
  экранных координатах. Она учитывает точки, другие подписи, границы графика и
  легенду; подписи, для которых действительно нет места, не выводятся.
- Обозначение вида `+1` удалено. Совпадающие отражения отмечаются дополнительной

  выбора точки.
- В разделе «Отображение» добавлен общий ползунок масштаба точек от 25 до 300%.
  Он изменяет обе фазы одновременно, не меняя их индивидуальные коэффициенты,
  координаты или интенсивности.
- Там же добавлен переключатель подписей углов. Он скрывает числовые угловые
  обозначения, сохраняя окружности и линии сетки.
- Экранный алгоритм размещения подписей вынесен в независимый сервис и может
  быть повторно использован будущим интерфейсом PySide6.

## Изменения в 2.9.8

- В расчётной полюсной фигуре добавлено наложение второй CIF-фазы или фазы,
  заданной параметрами ячейки. Фазу можно выбрать из общего пула проекта либо
  открыть отдельной кнопкой «Открыть CIF поверх…».
- Обычная галочка в панели проекта по-прежнему заменяет текущую расчётную фазу.
  Только явная команда «Добавить поверх…» сохраняет первую фазу; одновременно
  допускаются не более двух расчётных фаз.
- Для обеих фаз независимо задаются постоянный цвет, прозрачность и размер
  точек. Возле графика выводится легенда с названиями и цветами фаз.
- Вторая фаза получила отдельные центрирование по (h k l), абсолютный поворот и
  относительный поворот. Числовые повороты первой фазы продолжают работать
  независимо.
- При двух фазах вращение мышью блокируется, а окраска по d и расчётной
  интенсивности становится недоступной. После удаления второй фазы предыдущий
  режим окраски восстанавливается.
- Удаление любой из двух фаз через общую панель корректно обновляет график; при
  удалении основной фазы наложенная фаза становится основной.
- Состояние одного расчётного слоя выделено в независимую модель
  `CalculatedPoleLayer`; ограничение на одну явную накладку проверяется без GUI.


## Просмотр измерений и CIF

- Двухколоночные XY/TXT/DAT/CSV в просмотрщике по умолчанию получают ось
  **2θ**. Это назначение смысла первого столбца, а не преобразование чисел.
  У выбранного набора появляется пояснение и выбор оси. Для rocking-кривой
  выберите **ω** или другую соответствующую координату. Явный выбор оси
  сохраняется при передаче кривой между вкладками в текущем сеансе.
- Загрузка CIF и изменение λ доступны и при других осях измерений. В этом
  случае CIF отображается по отдельной шкале 2θ; её границы задаются в блоке
  «Отдельная ось CIF, 2θ». Для совместимых 2θ-сканов оси связаны при
  панорамировании и масштабировании.
- Переключатель «Режим CIF» оставляет фазы в отдельной нижней области либо
  накладывает их на измеренную кривую. В режиме наложения высота CIF задаётся
  независимо от шкалы интенсивности и не меняет её границы. Для осей ω, θ, χ,
  φ и линейных координат используется только отдельный режим.
- Горизонтальная и вертикальная полосы прокрутки активируются, когда текущий
  диапазон уже полного диапазона данных. Это позволяет вручную перемещать
  область после Zoom или Pan; исходные данные при этом не изменяются.
- Цвет меняется кнопкой «Цвет» у выбранного набора. Кнопки «Выше»/«Ниже»
  и перетаскивание строк меняют порядок отдельно внутри измерений и CIF.
  При положительном вертикальном сдвиге первый набор списка расположен выше.
- Разделитель между областями перетаскивается левой кнопкой мыши при
  выключенных режимах Pan/Zoom панели Matplotlib. «Высота CIF, %» задаёт
  долю высоты от 10 до 85%. Масштаб и исходные интенсивности не меняются.
- Подписи фаз закреплены у левого края своей области; длинные подписи
  ограничены её границами. Полное название остаётся в списке наборов.
- «Структура CIF» открывается отдельной верхней вкладкой либо кнопкой у
  выбранного CIF. Абсолютные углы отсчитываются от ориентации, заданной hkl;
  относительные повороты последовательно применяются к текущему положению
  вокруг неподвижных осей, в порядке X, Y, Z. Отображение согласовано с
  существующим просмотром структуры в расчётной полюсной фигуре.
- Полиэдры, настройка правил связей и переключатели отдельных элементов
  в эту версию не входят. Связи остаются приближёнными, как в прежнем
  просмотре структуры: по ковалентным радиусам, для оксидов — пары с O.

## Работа с подложками

1. Подключите нужные измерения к разделу **Просмотр** в общей панели проекта.
2. Нажмите **Отправить в сравнение** внизу страницы графиков. Откроется одно
   модальное окно со всеми совместимыми измерениями по оси 2θ.
3. При необходимости загрузите в этом окне папку подложек.
4. Свободно перемещайте карточки по рабочему полю. Наложение карточек создаёт
   активную группу; к группе можно добавлять другие измерения и подложки.
5. Откройте внутреннюю вкладку **Галерея и результаты**. В ней отображаются
   графики всех активных групп.

Щелчок по карточке включает или отключает её группу. Перетаскивание карточки
в сторону от остальных исключает её из группы. Правый щелчок по любой карточке
открывает отправку отдельной кривой в просмотрщик или коррекцию; для подложки
там же доступно создание копии.

## Форматы и ограничения

- RAW: `RAW1.01` и `RAW4.00`;
- XRDML: одномерный скан хотя бы с одной читаемой координатной осью;
- расчётные данные CIF доступны только при отображении видимых кривых по 2θ;
- текстовые данные: первые два числовых столбца;
- экспериментальная полюсная фигура: RAW с диапазонами по φ при разных χ;
- CIF с объявленной непримитивной пространственной группой должен содержать
  явные операции симметрии – программа не подменяет такой файл структурой P1.
- CIF-токенизатор поддерживает внутренние апострофы и их запись с обратной
  косой чертой, встречающуюся в файлах Crystallography Open Database.

Коррекция создаёт набор с суффиксом `shifted`. Его можно добавить новым объектом
либо заменить им исходный объект внутри текущего проекта; прежний набор при
замене сохраняется во внутренней истории. Кнопка сохранения работает независимо
от этих двух действий. Перезапись исходного файла требует отдельного
подтверждения.

При выборе точки или области аппроксимации коррекция сохраняет текущие границы
графика. Начальные границы оси X определяются по отображаемой положительной
интенсивности без одиночных удалённых координат.

Для RAW исходный двоичный файл не перезаписывается: скорректированную кривую
можно добавить в проект или заменить ею исходный объект либо сохранить как XY. Запись
исправленного XRDML доступна только для исходных XRDML, открытых по оси 2θ,
поскольку двоичный писатель RAW в приложение намеренно не включён.
