# XRD Combine 3.0.0a16.7

Исправляющая итерация переноса графиков на PyQtGraph. Matplotlib пока сохранён
как эталонный движок и выбирается через `Правка → Отрисовщик (тест)`.

## Изменения

- в Comparison возвращены все четыре режима интенсивности: linear, log, exp и
  square;
- возвращена кнопка смены режима Y, а выбранный режим снова сохраняется в
  настройках группы;
- галерея Comparison снова состоит из компактных двухколоночных миниатюр;
- расчётная дифрактограмма в «Структурах» перенесена на общий
  `PyQtGraphViewerPlot`;
- для расчётной дифрактограммы намеренно оставлена только линейная шкала;
- сохранены штрихи, гауссов профиль, компоненты излучения, легенда, настройки
  графика, прямоугольное масштабирование и PNG-экспорт;
- общие настройки толщины линий применяются и к графику в «Структурах»;
- `unit-cell-gui` теперь настраивает совместные OpenGL-контексты до создания
  `QApplication`, как требуется версии 0.2.1;
- первый расчёт отражений фазы в основном Viewer выполняется вне GUI-потока,
  поэтому загрузка фазы не блокирует окно приложения.

## Проверка зависания

Проверена последовательность из отчёта на файле
`2310011 (KNbO3 Bmm2)(8).cif`: загрузка в «Структуры», переход в «Просмотр» и
включение отображения. CIF содержит 10 атомов после раскрытия симметрии и даёт
70 отражений в диапазоне 5–120°. Последовательность завершилась без зависания
с Matplotlib и PyQtGraph.

## Автоматическая проверка

Из исходного дерева прошли 148 из 149 тестов. Один тест OpenGL-снимка структуры
корректно пропущен, поскольку Qt offscreen не предоставляет графический
контекст. Проверка повторяется после распаковки передаваемого ZIP-архива.

## Установка

```bash
python -m pip install -r requirements.txt
python run_xrd_combine.py
```
